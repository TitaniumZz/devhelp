# 🎮 Game Development Time Calculator

A simple Python calculator that helps game developers calculate the total time spent working on a game project.

## 📌 About the Project

The Game Development Time Calculator is a beginner-friendly Python project developed for the GEP1316 Coding Literacy course.

The program takes the developer's name, daily working hours, and the number of days spent on a project. It calculates the total working time and categorizes the development duration.

## ✨ Features

- Takes user information through input.
- Calculates total working hours.
- Categorizes development time into three levels:
  - **Short:** Less than 30 hours
  - **Medium:** 30–100 hours
  - **Long:** More than 100 hours
- Checks whether the project is completed.
- Displays a formatted development report.

## 🛠️ Technologies Used

- Python 3
- `input()` for user interaction
- `int()` and `float()` for data conversion
- Conditional statements (`if`, `elif`, `else`)
- Arithmetic and comparison operators
- f-strings for formatted output

## ▶️ How to Run

1. Make sure Python 3 is installed on your computer.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command in your terminal:

```bash
python hesaplayici.py
```

5. Follow the instructions displayed in the terminal.
